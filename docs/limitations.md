# Limitations

- Updated Table 2/3 results are aggregate reports without the producing code revision/environment or final fold records. New inferential claims cannot be recovered from those means.
- Earlier main-text tests use datasets as blocks. Shared classifier/fold results must not be treated as independent datasets. Non-significance is not equivalence.
- Subgroups are constructed; prior development exposure, duplicate feature vectors and related source families constrain generalization.
- Frozen quota rounding has no universal nonzero/nonnegative guarantee. The seed remainder favours earlier rows and neighbour self-exclusion assumes tie ordering. The release does not silently repair these behaviours.
- The KMeans transfer intervention changes membership handling as well as rescue/quota; it is not an isolated two-switch causal experiment.
- AW reconstruction depends on documented assumptions and does not establish how the original article's experiments were conducted. Invalid controls are diagnostic only.
- The supplied paper states Code Availability: Not applicable. The authors should update that declaration when the repository is actually published; assembly does not claim an upload occurred.
- Broad original audit scripts are retained for source completeness and can require inputs outside this main-paper selection. Supported entry points and tested operations are listed in the release report.
