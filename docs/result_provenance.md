# Result provenance

Tables 2 and 3: updated author-supplied rounded measurements from the authoritative final Elsevier main.tex. No old summary Table 2/3 versions are published. Table 2 retains its explicitly historical mean-rank column because that column appears in the main paper.

Tables 4-7 and main-text starvation, ablation, sensitivity, transfer, subgroup-position, statistical and independence analyses: saved earlier-run evidence, as disclosed in the main paper. Baseline rows in Tables 2/3 also come from that supporting run. File dates and co-location do not establish a common producing run.

The supporting fold-level files necessarily contain earlier full-method measurements used by the retained main-paper analyses. Those files are not alternative final Table 2/3 summaries. Removing them would remove the evidence behind the retained main text. No final fold-level records were invented from new aggregate means.

The source manifest fingerprints each copied input. SOURCE_PRESERVATION.json records source hashes relative to the assembly workspace. Final release checks record figure hashes and expected new means. General raw table CSVs preserve displayed text, including inequalities and scientific notation, rather than pretending rounded values are unrounded experiments.
