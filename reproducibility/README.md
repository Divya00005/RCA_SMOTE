# Reproducibility records

protocols/ preserves the fixed experimental designs; development_selection/ preserves selected development/freeze evidence. aw_baseline_reconstruction/ supports main-text Section 8.3. Its invalid-control files are explicitly invalid diagnostic evaluations.

environments/original_reported_requirements.txt preserves the old experiment's reported dependency pins. environments/audit_environment_lock.txt describes the independent reconstruction environment used for bounded release checks. Neither identifies the unprovided environment that produced the updated aggregate means.

Source hashes, file adaptations, static checks and scientific limitations are documented in SOURCE_MANIFEST.json, RELEASE_VERIFICATION.json and docs/. Git history is not initialized by assembly.
