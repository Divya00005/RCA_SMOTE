# Dataset provenance

DATASETS.md and datasets.csv describe all 51 main-paper tasks and the subset rules. DATA_HASHES.csv contains the historical audit hashes; its source-relative paths describe the original environment. New downloads belong under ignored data/raw/ and require matching the recorded content, not just matching a dataset name. Run code/scripts/fetch_data.py through scripts/run.py; KEEL links are printed for manual download.

No raw datasets, cached OpenML data or downloaded upstream AW source are bundled for public upload. Sources include PMLB, OpenML-CC18, KEEL and the imbalanced-learn benchmark collection.
